# Multi-Asset-ETF-Trend-Momentum-Strategy
本策略是一套只做多、全额持仓的美国上市多资产ETF系统化趋势动量策略。策略覆盖股票、债券、商品及外汇类ETF，每月最后一个完整交易日收盘后，根据21、63、126和252个交易日的多周期横截面动量进行排名，跳过最近5个交易日，并要求63日动量为正且价格高于200日均线。下一交易日执行，通常选择排名靠前的最多8只ETF，采用近似等权配置；当市场趋势转弱时，通过趋势风险开关和防御型ETF降低权益暴露。组合不做空、不使用杠杆、不交易期权或期货。回测和执行模型纳入成交量约束、滑点、手续费、部分成交及未成交记录，并严格避免使用未来数据。
